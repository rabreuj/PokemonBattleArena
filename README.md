# ⚡ Pokémon Battle Arena

Simulador de combate Pokémon por consola desarrollado en Java como proyecto educativo.

## 🎮 Características

- Combate por turnos con sistema de velocidad
- 12 Pokémon con 48 movimientos únicos
- 3 niveles de dificultad (Fácil, Medio, Difícil)
- Soporte bilingüe (Español e Inglés)
- Música de fondo dinámica
- Interfaz de consola con colores y emojis

## 🚀 Cómo jugar

1. Descarga el ZIP desde Releases
2. Descomprime
3. Doble clic en `Iniciar.bat`

## 🎯 Requisitos

- Java 17 o superior
- Windows 10/11

## 📚 Tecnologías

- Java 17
- Eclipse IDE
- javax.sound.sampled (audio)
- Git + GitHub
